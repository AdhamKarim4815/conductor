# /slides

Run the Conductor workflow with this preset.

1. Ask what you need, in one round: topic and purpose, audience, number of slides or minutes to present, required structure or rubric (check the course pack), material she has to attach, group or solo, and the deadline.
2. If research is needed, dispatch researchers first. Then dispatch the builder with the research and a full brief for slide-by-slide content and speaker notes.
3. Run the strict-checker against the rubric if it is graded.
4. Create the deck from the Slides type if it is available, otherwise as a PowerPoint file. Tell her she can download it as PowerPoint or PDF.
