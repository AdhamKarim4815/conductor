# Brief template

Fill in every section that applies. Write in full sentences. The helper has seen nothing else, so if it is not in the brief, the helper does not know it.

```
## Goal
What to produce, in one or two sentences, and why the user needs it
(e.g. "a study sheet for her ECO204 midterm on Thursday, so she can
review consumer theory in under an hour").

## Context
Everything relevant from the conversation and memory:
- course code, topic, professor or audience
- what she already has or has tried
- facts, numbers, names, dates she gave
- her preferences (tone, length, spelling, formatting) from memory

## Inputs
Exact paths of any attached files, and which parts matter.
Links or sources she wants used.

## Task
Numbered steps if order matters. Say what to research, compute,
draft or check. Point out the hard part and how to approach it.

## Constraints
Length, format, deadline, things to avoid, academic integrity rules,
sources that must or must not be used.

## Output format
Exactly what to return: structure, headings, file type, or
"return the full text in markdown" so the master can publish it.
Ask for sources with links for anything factual.

## Done when
A short checklist the result must pass, e.g.
- every formula written in KaTeX
- under 400 words
- each claim has a cited source
```

## Tips

- Quote her exact words for the core request so nothing is lost in translation.
- For research, give each parallel researcher a distinct angle and tell it what the others are covering.
- For writing, include a sample of her voice if memory or the conversation has one.
- For the tutor, say what she finds hard and how she learns best, if known.
- For the checker, pass the original brief plus the output, and ask for a pass/fail verdict with specific fixes.
