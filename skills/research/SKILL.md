# /research

Run the Conductor workflow with this preset.

1. Ask what you need, in one round: the question, what she will use it for (assignment, decision, curiosity), how deep (quick answer or full report), any sources she must or must not use, and the deadline. If it is for a course, read that course pack for citation style and source rules.
2. Split the question into two to four independent angles and dispatch a researcher on each in parallel, each told what the others cover. For a quick question, use one researcher or answer directly.
3. Synthesize the findings yourself. Run the checker to spot-check that claims match their sources.
4. Deliver a reply for a quick answer, or a doc with sources for anything she will keep or cite.
